站点已经在本地跑起来了，用 **Hexo 8.1.2 + Butterfly 5.7.0** 搭建。

<!-- more -->

## 常用命令

```bash
# 新建文章
npx hexo new post "文章标题"

# 本地预览（默认 http://localhost:4000）
npm start

# 生成静态文件到 public/
npm run build
```

## 写点什么

- 闲时追番
- 忙时偷闲
- 蒜了蒜了，搞不赢的

## 小提示

主题配置不在 `themes/` 目录里改，而是改根目录下的 `_config.butterfly.yml`；站点信息改 `_config.yml`。改完配置需要重启本地服务才能生效。
